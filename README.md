# SILR DTU website (React + Tailwind CSS v4 + Vite)

    npm install
    npm run dev      # http://localhost:5173
    npm run build    # output in dist/

Edit content in `src/data.js` (faculty, fellows, interns, news, departments).
Diagrams from the PDF are in `src/Diagrams.jsx`. Replace the SVG emblem in `src/App.jsx` with the real DTU logo (put the file in `public/` and use <img src="/logo.png">).
